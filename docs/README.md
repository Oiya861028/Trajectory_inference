# Trajectory_inference

Trajectory / RNA-velocity analysis of mouse early-embryo brain development
(PRJNA637987, E7.0–E10.0), with a joint integration against Brooks 2025
(E7.5–E8.75).

## Layout

```
docs/                 METHODS.md, README.md, progress deck
notebooks/            analysis notebooks (run on compute nodes via sbatch)
scripts/
  preprocess/         BAM -> h5ad, concatenation, barcode export, velocyto merge
  analysis/           CellTypist, dataset comparison, pseudobulk, joint plots
  slurm/              SLURM submission wrappers (*.sbatch)
  env/                patch_cellrank_env.py - re-applies the site-packages patches
  hooks/              pre-commit reference check (run install.sh to enable)
  paths.py            every path as one constant - import this, do not
                      hardcode; adding a file means adding a constant here
  check_references.py verifies every path reference resolves and that no
                      output has two writers
data/                 grouped by how far through the pipeline a file is
  raw/
    h5ad/             19 per-sample matrices straight out of bam_to_h5ad
    external/         reference genome + annotations (not tracked)
  interim/            working objects that later stages consume
    devbrain_E7-E10.h5ad            concatenated, cells called
    devbrain_E7-E10_processed.h5ad  QC'd, normalised, embedded
    devbrain_velocity.h5ad          + spliced/unspliced layers
    velocyto/                       loom intermediates (not tracked)
  processed/          analysis outputs, each the input to a figure or table
    devbrain_brooks_integrated.h5ad  joint 9-stage object
    devbrain_cellrank.h5ad           macrostates + fate probabilities
    devbrain_celltypist.h5ad         label transfer + marker scores
    devbrain_neural_lineage.h5ad     the isolated neural subset
results/
  figures/            one subdirectory per analysis stage, 01_ .. 09_
  tables/             small CSVs (tracked)
    metadata/           sample and QC tables
    cellrank/           per-run fate probabilities and compositions
  models/celltypist/  trained CellTypist models (not tracked; regenerable)
logs/                 SLURM stdout/stderr, grouped by job family (not tracked)
```

The three `data/` tiers are the convention: nothing in `raw/` is ever written
to after it lands, `interim/` holds objects that exist only to feed the next
step, and anything in `processed/` backs a figure or a table. Large binaries are
gitignored throughout and regenerated by the pipeline below.

## Pipeline

1. `scripts/slurm/fetch_count.sbatch` — per-sample array job: pull the original
   CellRanger BAM from SRA and count UMIs with `scripts/preprocess/bam_to_h5ad.py`.
2. `scripts/preprocess/combine_h5ad.py` — concatenate per-sample raw matrices and call
   cells with the CellRanger v2 ordmag heuristic →
   `data/interim/devbrain_E7-E10.h5ad`.
3. `scripts/slurm/run_inference_nb.sbatch` — execute `notebooks/inference.ipynb`
   in place (QC → HVG/PCA → UMAP → Harmony → hedgehog markers).
4. `scripts/preprocess/export_barcodes.py` + `scripts/slurm/velocyto_run.sbatch` — per-library
   spliced/unspliced counts for velocity.
5. `scripts/slurm/run_integration_nb.sbatch` — execute
   `notebooks/integration_devbrain_brooks.ipynb`; see also
   `scripts/analysis/compare_datasets.py` for the streaming dataset comparison.

## Paths and references

Paths live in one place, `scripts/paths.py`. Import from it rather than writing
a literal:

```python
import sys; sys.path.insert(0, "/project/imoskowitz/yubin/Trajectory_inference")
from scripts.paths import DEVBRAIN_PROCESSED, JOINT, fig, table
```

`fig("hedgehog")` returns the figure directory for that analysis stage and
creates it; register a new stage in `FIGURE_STAGES` and nothing else changes.

After moving or renaming anything, run

```
envs/cellrank_traj/bin/python scripts/check_references.py
```

It checks four things that fail in different ways: the script or notebook each
sbatch wrapper invokes (a typo here surfaces only once a job has a node), path
literals in code, the figures the deck asks for, and whether any output path has
more than one writer — because when two scripts write the same file, whichever
runs last silently wins. `bash scripts/hooks/install.sh` runs it before every
commit.

Both failures it was written for were real: after the directory reorganization,
four sbatch wrappers still pointed at `scripts/<name>.py` for scripts that had
moved into subdirectories, and `pca_plots.py` and `joint_pca_feature_plots.py`
were both writing `pca_scatter_*.png`.

## Methods

`docs/METHODS.md` documents each step with its parameters and the reasoning behind it,
including the validation tests for the batch-correction and integration steps
(one of which failed — Harmony on `chip` — and why it was rejected), and the two
local site-packages patches in `envs/cellrank_traj` that do **not** survive an
env rebuild.

## Data

The `.h5ad`/`.loom` matrices and reference annotations are deliberately not in
git (~6 GB). Regenerate them with the pipeline above, or copy them from the
project directory on the cluster.
